# sistema_correos

Módulo **Quejas y denuncias** alineado al sitio oficial [naucalpan.gob.mx](https://naucalpan.gob.mx/).

## Cómo verlo

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Abre `http://127.0.0.1:8080/quejas-denuncias/`.
